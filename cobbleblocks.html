Cobble Blocks

Overview

Cobble Blocks is a Cobblemon-themed lucky block style mod that lets you spawn random Cobblemon by breaking a special block: the Cobble Block.

From common Cobblemon to rare legendaries and mythicals, every break adds suspense and chaos to your adventure. It’s great for challenge worlds, arenas, or just spicing up normal Cobblemon gameplay.

While development is currently paused, existing versions can still be used on the Minecraft / Cobblemon versions they were built for.

How It Works

Basic Mechanics

  • Craft or obtain a Cobble Block.
  • Place it anywhere in the world.
  • Break the block like a normal block.
  • A random Cobblemon will spawn at the block’s location.
  • Spawns can range from starter tier to powerful legendaries and mythicals.

Integration with Cobblemon

The mod integrates with the Cobblemon mod, pulling from the Cobblemon registry to select random Cobblemon so it can create a lucky block style experience.

Key Features

🎲 Lucky Block Style Gameplay

Every Cobble Block break triggers a random Cobblemon spawn, making every use unpredictable.

⭐ Full Rarity Range

Spawns include common, rare, legendary, and mythical Cobblemon.

⚔️ Challenge & Event Friendly

Perfect for custom challenges, event arenas, battle towers, or YouTube content.

🎮 Simple to Use

No complicated setup just place and break blocks to start the chaos.
