Random Items

Overview

Random Items is a fun and unpredictable mod that adds an element of surprise to your Minecraft experience. Every player on the server automatically receives random items at configurable intervals, keeping gameplay exciting and dynamic.

The mod is 100% compatible with both vanilla items and items from any other installed mods. Whether it's a simple stick, a diamond block, or even creative only items like bedrock, every item in the game has a chance to be gifted to players!

Key Features

🎲 True Randomness

Every item in the game, including modded items, can be randomly given to players.

⏱️ Configurable Timing

Adjust how frequently items are given through the /setinterval command

🌐 Multiplayer Support

Works seamlessly on both singleplayer worlds and multiplayer servers.

🔧 Mod Compatible

Automatically detects and includes items from all installed mods.

🎮 Creative Items

Even creative only items like bedrock can appear in the random selection!

⚖️ Fair Distribution

All players receive items simultaneously, keeping gameplay balanced.

How It Works

Basic Mechanics

  • The mod runs on a timer system that triggers at regular intervals
  • When triggered, every online player receives one random item
  • Items are selected from the complete item registry (vanilla + mods)
  • Each player gets a different random item not everyone gets the same thing
  • Items are added directly to the player's inventory (or dropped if full)

Default Settings

By default, the mod gives items every 30 seconds, but this is fully customizable.

Configuration

The mod can be customized through the configuration file located in your config folder:

/setinterval <time_in_seconds>
